Welcome on OBS RPi's GitHub page! Here are all the scripts and binaries of our builds.

This project is made to allow you to stream or record through your Raspberry Pi.

Since the Raspberry Pi 4 integrates an hardware encoder, you can use it to stream.

Check the main repository here: https://github.com/obs-rpi/obs-rpi
